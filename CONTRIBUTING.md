# Contributing

Thank you for improving this NEC Civil Engineering MCQ Trainer.

Open an issue for bugs, wrong keys, accessibility problems, or code issues.
When possible, include the question number, expected result, relevant
standard or code reference, device/browser details, and reproduction steps.

Submit focused pull requests and describe your changes. Test the standalone
`index.html` in a browser before requesting review.

Please do **not** contribute copied questions or materials from commercial
publications without the necessary permission. Check current official NEC
syllabus and code versions before proposing factual corrections.

The hosted application stores progress locally. No hosted account system is
available through GitHub Pages.
